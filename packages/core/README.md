# @apricotjs/core

The engine under Apricot, without React: scenes, rendering with three.js on WebGPU, cameras, lights, placement and motion.

Apps usually use it through [`@apricotjs/react-native`](https://www.npmjs.com/package/@apricotjs/react-native).

Documentation: https://matthiasbrandolin.dev/apricot
